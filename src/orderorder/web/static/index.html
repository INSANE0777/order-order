Twelve ways a citation lies.

Each of these is a real failure mode — invented cases, mis-typed citations, a dissent quoted as the law. Each has a detector, and each detector’s catch rate is measured against a planted holdout. The ones still waiting on a model say so rather than guess.

    Phantom

    A case that does not exist, invented by a model or a memory.

    100% caught

Quote or nothing.

A citation is never “probably fine”. It comes back in one of three states, and the engine refuses to collapse them into each other.

Supported

The paragraph contains the proposition, in the court’s own words, verified against the stored text.

Checked, and not supported

The judgment was read and the paragraph does not carry the claim. No softening of the verdict.

Not checked

No model configured, a provider down, a retrieval miss — reported as what it is, never disguised as either of the others.

Start from the proposition.

Every paragraph of every judgment held is searched for the line that backs it. A passage that is not the court speaking is dropped before it reaches you — an advocate's submission matches a proposition's words better than a holding does, because it is stated without the qualifications.
